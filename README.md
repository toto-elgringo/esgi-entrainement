# ESGI Entraînement

Cours, quiz et exercices corrigés automatiquement : **Rust**, **Maths pour l'informatique**, **Maths pour le big data**.

**Le site : https://toto-elgringo.github.io/esgi-entrainement/**

Ta progression est enregistrée dans ton navigateur.

## Compiler les exercices Rust

En ligne, tout marche sauf « Exécuter » / « Vérifier » en Rust. Pour ça, installe [Node.js](https://nodejs.org) et [Rust](https://rustup.rs), puis :

```bash
git clone https://github.com/toto-elgringo/esgi-entrainement.git
cd esgi-entrainement
npm start
```
