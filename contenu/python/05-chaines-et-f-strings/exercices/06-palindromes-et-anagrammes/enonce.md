Écris deux fonctions qui ignorent **les espaces, la ponctuation et les majuscules** :

- `est_palindrome(phrase)` : `True` si la phrase se lit pareil dans les deux sens. `est_palindrome("Engage le jeu que je le gagne")` → `True` ;
- `sont_anagrammes(a, b)` : `True` si les deux textes utilisent exactement les mêmes lettres, autant de fois. `sont_anagrammes("Chien", "niche")` → `True`.

Une chaîne vide (ou sans lettre) est considérée comme un palindrome.
