Écris quatre fonctions :

- `compte_a_rebours(n)` : renvoie la liste `[n, n-1, ..., 1, 0]`, construite avec une boucle **`while`**. `compte_a_rebours(3)` → `[3, 2, 1, 0]` ;
- `premier_multiple(nombres, k)` : renvoie le **premier** nombre de la liste divisible par `k`, ou `None` s'il n'y en a pas. Arrête la boucle dès que tu l'as trouvé ;
- `somme_positifs(nombres)` : renvoie la somme des nombres **positifs ou nuls** de la liste, en sautant les négatifs avec **`continue`** ;
- `nombre_de_voyelles(texte)` : renvoie le nombre de voyelles (`a e i o u y`, majuscules comprises) dans le texte.

N'utilise pas `sum()` : le but est de t'entraîner aux boucles.
