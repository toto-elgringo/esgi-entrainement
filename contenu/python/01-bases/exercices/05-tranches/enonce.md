Écris ces fonctions en utilisant **uniquement des tranches** (pas de boucle) :

| Fonction | Renvoie | Exemple |
|---|---|---|
| `premiers(l, n)` | les `n` premiers éléments | `premiers([1, 2, 3, 4], 2)` → `[1, 2]` |
| `derniers(l, n)` | les `n` derniers éléments | `derniers([1, 2, 3, 4], 3)` → `[2, 3, 4]` |
| `un_sur_deux(l)` | les éléments d'indice pair | `un_sur_deux([1, 2, 3, 4, 5])` → `[1, 3, 5]` |
| `inverser(s)` | la chaîne à l'envers | `inverser("Hello")` → `"olleH"` |
| `est_palindrome(mot)` | `True` si le mot se lit pareil dans les deux sens, sans tenir compte des majuscules | `est_palindrome("Kayak")` → `True` |

Attention : `derniers(l, 0)` doit renvoyer une liste vide.
