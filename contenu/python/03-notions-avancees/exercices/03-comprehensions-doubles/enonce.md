Écris ces fonctions avec des listes en compréhension :

- `mots_majuscules(ligne)` : les mots de la ligne qui ne contiennent que des lettres, en majuscules. `mots_majuscules("Il y a 3 chats")` → `["IL", "Y", "A", "CHATS"]` ;
- `combinaisons(prenoms, noms)` : toutes les combinaisons « prénom nom ». `combinaisons(["Ana", "Bob"], ["Roy"])` → `["Ana Roy", "Bob Roy"]` ;
- `couples_ordonnes(E)` : tous les couples `(i, j)` d'éléments de `E` avec `i < j`. `couples_ordonnes([1, 2, 3])` → `[(1, 2), (1, 3), (2, 3)]` ;
- `table(n)` : la table de multiplication de 1 à `n`, sous forme de liste de lignes. `table(3)` → `[[1, 2, 3], [2, 4, 6], [3, 6, 9]]`.
