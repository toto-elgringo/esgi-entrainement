Écris chaque fonction en une ligne, avec un dictionnaire ou un ensemble **en compréhension** :

- `longueurs(mots)` : le dictionnaire mot → longueur. `longueurs(["chat", "ours"])` → `{"chat": 4, "ours": 4}` ;
- `inverser(d)` : le dictionnaire avec clés et valeurs échangées ;
- `abordables(prix, budget)` : seulement les articles dont le prix est inférieur ou égal au budget. `abordables({"kiwi": 5, "melon": 8}, 6)` → `{"kiwi": 5}` ;
- `initiales(mots)` : l'**ensemble** des premières lettres des mots non vides, en minuscules. `initiales(["Chat", "chien", "ours"])` → `{"c", "o"}`.
