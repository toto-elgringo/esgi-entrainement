Écris chaque fonction en **une seule ligne**, avec une liste en compréhension :

| Fonction | Renvoie | Exemple |
|---|---|---|
| `carres(n)` | les carrés de 0 à `n - 1` | `carres(4)` → `[0, 1, 4, 9]` |
| `positifs(l)` | les nombres strictement positifs de `l` | `positifs([3, -1, 0, 7])` → `[3, 7]` |
| `opposes_des_pairs(n)` | l'opposé de chaque nombre pair de 0 à `n - 1` | `opposes_des_pairs(10)` → `[0, -2, -4, -6, -8]` |
| `longueurs(mots)` | la longueur de chaque mot | `longueurs(["a", "abc"])` → `[1, 3]` |
