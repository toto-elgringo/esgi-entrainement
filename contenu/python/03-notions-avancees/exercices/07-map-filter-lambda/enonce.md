Écris ces fonctions avec `map`, `filter` et des fonctions `lambda`. Chacune doit renvoyer une **liste** :

- `convertir_entiers(textes)` : `["1", "22"]` → `[1, 22]` ;
- `multiples_de(l, k)` : les éléments de `l` multiples de `k` ;
- `produits(l1, l2)` : les produits terme à terme. `produits([1, 2, 3], [4, 5, 6])` → `[4, 10, 18]` ;
- `avec_tva(prix, taux)` : chaque prix multiplié par `1 + taux`, arrondi à 2 décimales. `avec_tva([10, 2.5], 0.2)` → `[12.0, 3.0]`.
