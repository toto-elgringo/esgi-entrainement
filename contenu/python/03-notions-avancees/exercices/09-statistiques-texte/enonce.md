Le programme lit un nombre `n`, puis `n` lignes de texte. Il affiche :

- le nombre de lignes ;
- le nombre total de mots ;
- le mot le plus long (le premier rencontré en cas d'égalité) ;
- le nombre de mots **distincts** ;
- la liste des mots distincts par ordre alphabétique, séparés par `, `.

Avec l'entrée :

```text
3
le chat dort
le chien aboie fort
un oiseau chante
```

le programme doit afficher **exactement** :

```text
Lignes : 3
Mots : 10
Plus long : oiseau
Mots distincts : 9
Ordre alphabétique : aboie, chante, chat, chien, dort, fort, le, oiseau, un
```
