Écris la fonction `maximum(start)` qui renvoie la plus grande valeur de la liste. La liste n'est **jamais vide**.

| Liste | Résultat |
|---|---|
| `3 -> 9 -> 2` | 9 |
| `-4 -> -2 -> -8` | -2 |
| `5` | 5 |

> [!warning] Le piège du 0
> Initialiser le maximum à 0 donnerait 0 pour `-4 -> -2 -> -8`, alors que 0 n'est même pas dans la liste.
